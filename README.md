# Retirement App Website

Minimal static website for the iOS app **Retirement App**.

## Files

- `index.html` - Home page
- `privacy.html` - Privacy Policy

No build tools, frameworks, or package managers are required. The site works by opening `index.html` directly in a browser.

## Deploy to GitHub Pages

1. Push these files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch that contains these files, usually `main`.
6. Select the root folder, `/`.
7. Save the settings.

GitHub Pages will publish the site after the first deployment finishes.
